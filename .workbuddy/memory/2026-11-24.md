# 2026-11-24

## 金价查询显示过期价（884.5 → 应为 788 左右）修复

- 现象：用户看到 Au99.99 仍是 884.5 元/克，而 11/24 上金所延时行情为 788.10（新浪实时 787.6~788.4）。
- 根因：`https://tmini.net/api/gold-price?type=json` 启用了 JS 安全校验，任何 UA / 参数都返回 `<script src="/_guard/html.js?js=rotate_html"></script>`（HTTP 200）。`fetchGoldQuote` 里 `response.json()` 抛异常 → 返回 null → `loadGoldQuote` 无限期回退本地缓存，把 10 月的旧价当用户看到的「今日金价」；页面只有一行黄色小字提示，主数字依然醒目，容易误导。
- 数据源整体替换（两路独立请求，任一路失败不影响另一路）：
  - 现货：`https://hq.sinajs.cn/list=gds_AU9999,gds_AUTD,gds_AGTD,gds_PT9995,gds_AU100G,hf_XAU`，**必须带 `Referer: https://finance.sina.com.cn`**（否则返回 `Forbidden`）。GBK 文本，只解析 ASCII 数字字段：0 最新价 / 4 最高 / 5 最低 / 6 时间 / 8 今开 / 12 日期；中文名乱码忽略，用 `SPOT_NAMES` 映射。单位注意：白银 T+D 是元/公斤，伦敦金是美元/盎司。
  - 零售：`https://v2.xxapi.cn/api/goldprice`，JSON 零鉴权；`data.precious_metal_price[].gold_price` 品牌价、`data.bank_gold_bar_price[]` 金条（返回「浦发银行投资金条」这类合并串，需 `splitBankName` 拆银行 + 产品）。
- 真实网络端到端验证（Node 转译 gold.ts 后直连）：Au99.99 788.37、今开 778、高 794.5、低 776、更新 09:37:03；11 家品牌、6 家银行、5 个参考品种，与官方行情吻合。
- 防复发：`goldStorage.ts` 新增 `GOLD_STALE_MAX_AGE = 24h`，缓存超过一天直接丢弃（宁可显示获取失败也不展示旧价）；`GoldPriceScreen` 在结果为空时清空 quote，stale 时改红色横幅「非实时行情…历史快照」+ 主卡右上角红色「历史快照」徽标；HELP_TEXT / footer / README「金价查询说明」全部同步。
- 代码结构：`gold.ts` 去掉 `parseGoldQuote`，改为 `parseGoldSpotText` / `parseGoldRetail` / `buildGoldQuote` 三段；`GoldQuote` 等对外类型与展示函数保持不变，所以 UI 数据结构零改动。
- 测试：重写 `gold.test.ts`、新增 `goldStorage.test.ts`（含「反爬 HTML 不产出品种」「35 天前缓存被丢弃」等回归用例）。全量 12 suites / 172 tests 通过，tsc 通过，lint 0 error（仍是 3 个历史 warning）。
