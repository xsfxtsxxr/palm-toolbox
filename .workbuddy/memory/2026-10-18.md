# 房贷计算器（第一个工具）实现说明

> 代码入口：`src/screens/MortgageCalculatorScreen.tsx`
> 结果页：`src/screens/RepaymentPlanScreen.tsx`
> 计算引擎：`src/utils/mortgage.ts`
> 本文档核对时间：2026-10-20（以当前代码为准）

---

## 1. 功能定位

等额本息房贷的「提前还款」测算工具：输入剩余本金、提前偿还金额、首次还款日期、贷款总期数、年利率与剩余期数，选择「减少月供」或「缩短期限」，输出原月供、新月供、节省利息、剩余期数与逐期还款计划，并支持导出明细。

首页工具箱第一格，副标题「提前还款测算」，带「热门」标记。

## 2. 页面流程

```
首页 / 全部工具
      ↓ 点击「房贷计算器」
房贷计算器（输入页）
      ↓ 开始计算（校验通过）
还款计划（结果页）── 导出 CSV / 再算一次
      ↓ 同时写入 CalculationContext（内存，最多 20 条）
统计 Tab（累计计算次数 / 累计节省利息 / 最近一次 / 前 12 期构成图）
```

输入页在金额合法时**实时预览**「提前还款后预计节省利息」（蓝紫渐变金额），无需点击即可看到数值变化。

## 3. 输入项与默认值

| 字段 | 默认值 | 交互方式 | 说明 |
| --- | --- | --- | --- |
| 剩余贷款总额 | 空 | 数字键盘 + 千分位，后缀「元」 | 提前还款前的剩余本金 |
| 提前偿还金额 | 空 | 同上 | 必须小于剩余本金 |
| 首次还款日期 | 下个月的 15 日 | 年月日底部选择器（`MonthPickerModal`） | 明细表从「下一个未到期的还款日」开始 |
| 贷款总期数 | 360 | 数字输入（最多 3 位），后缀「月」 | 用于推算剩余期数 |
| 贷款年利率 | 4.9% | 利率选择器（`RatePickerModal`：LPR 预设 + 自定义） | 年利率，内部换算为月利率 |
| 剩余期数（月） | 自动推算 | 期数选择器（`PeriodPickerModal`） | 改日期 / 总期数会重置为自动值 |
| 还款方式 | 减少月供 | 分段控件 | `reducePayment` / `reduceTerm` |

自动剩余期数规则：从首次还款日按月递推，找到第一个「不早于今天」的还款日，剩余期数 = 总期数 − 已过期数。扣款日当天仍算本月（如 5 月 15 日当天，仍从 5 月开始）。

## 4. 计算模型

**等额本息月供**

```
M = P × r × (1+r)^n / ((1+r)^n − 1)
r = 年利率 / 100 / 12      n = 期数      P = 本金
```

**月供不变时反解期数**

```
n = ceil( −ln(1 − P·r / M) / ln(1+r) )
```

**两种提前还款模式**

| 模式 | 规则 | 结果 |
| --- | --- | --- |
| 减少月供 `reducePayment` | 剩余期限 `n0` 不变，按 `P − 提前还款额` 重算月供 | 月供下降，利息减少 |
| 缩短期限 `reduceTerm` | 月供保持原月供 `M0`，反解新的期数 | 期数减少，利息节省更多 |

**其他口径**

- 节省利息 = max(0, 提前还款前总利息 − 提前还款后总利息)
- 缩短月数 = 原剩余期数 − 新剩余期数（全额还清时等于原剩余期数）
- 全额还清（提前还款额 ≥ 剩余本金）：无后续月供、计划表为空、节省全部剩余利息
- 零利率：月供 = 本金 ÷ 期数；反解期数 = ceil(本金 ÷ 月供)
- 月供不足以覆盖利息（`1 − P·r/M ≤ 0`）时按上限 600 期截断

## 5. 边界与校验

- 剩余本金必须 > 0，提前偿还金额必须 > 0 且 **小于** 剩余本金（`validateInput`，不满足时 Toast 提示）
- 贷款总期数需在 1 - 600 之间（`MAX_PERIODS = 600`）
- 剩余期数需 > 0，可通过期数选择器手动调整
- 金额展示四舍五入到元（`fmtMoney` / `fmtYuan`），计算过程保留双精度
- 末期自动吸收尾差：最后一期按「剩余本金 + 当期利息」结清，保证余额归零
- 短月份对齐：还款日为 31 日时，2 月按 28/29 日、4 月按 30 日生成
- `fullyRepaid`（全额还清）是引擎兜底分支：UI 校验会拦下「相等」的情况，因此页面实际走不到，但结果页仍保留「贷款已全额还清」提示卡

## 7. 结果页说明

- **统计卡**：原月供、新月供、节省利息（深绿高亮）
- **明细表列**：还款日 / 月供总额 / 月供本金 / 月供利息 / 剩余总额；默认展示 12 期，可「查看全部期数」（内部滚动，最高 430）
- **全额还清**：不展示明细表，改为「贷款已全额还清，共节省利息 ¥xxx」提示卡
- **导出**：CSV 表头 `还款日期,月供总额,月供本金,月供利息,剩余总额`，金额四舍五入到元，通过系统分享面板发送
- **再算一次**：返回输入页，保留原有输入

## 8. 测试覆盖（`src/utils/mortgage.test.ts`，15 例）

| 分组 | 关键断言 |
| --- | --- |
| `annuityPayment` | 100 万 / 4.9% / 360 期 → 月供 5,307.27；零利率 = 本金 ÷ 期数 |

| `getRemainingPaymentInfo` | 扣款日当天算本月；超过扣款日顺延并扣减期数；短月按月末 |
| `validateInput` | 合法通过；空值 / 超额返回对应文案 |

## 9. 已知约定与限制

- 仅支持**等额本息**，未实现等额本金
- 假设利率在剩余期限内不变，不考虑 LPR 重定价、提前还款违约金、当期已计利息
- 提前还款自「下一个未到期还款日」生效，不单独计算提前还款当日到下一扣款日的利息
- 由于 UI 要求提前还款额 < 剩余本金，「全额还清」只能通过引擎直接调用触发
- 计划表日期由 `paymentDateLabel` 生成，短月自动取月末
- 计算结果通过导航参数整包传递（含完整 `schedule`），不做持久化
- 计算历史为**内存态**，重启 App 清空，最多 20 条
- 金额展示到元；接口层保留双精度，末期吸收尾差
