# 掌中工具箱 Palm Toolbox

跨平台（iOS / Android）效率工具集 App。基于 **Expo + React Native + TypeScript** 开发，一套代码同时构建双端应用。

当前版本已实现 **房贷计算器（提前还款测算）**、**存款计算器（定期单利测算）**、**理财计算器（活期理财收益）** 与 **个税计算器（工资薪金累计预扣法）**，其余 5 个工具已完成 UI 入口与图标，将按路线图陆续上线。

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（ Expo Go 扫码预览，或按 a / i 打开模拟器）
npm start

# 类型检查
npm run typecheck

# 单元测试（房贷 + 存款 + 理财 + 个税计算引擎，共 48 个用例）
npm test
```

- **iOS**：`npm run ios`（需要 macOS + Xcode）
- **Android**：`npm run android`（需要 Android Studio + 模拟器）
- 无 Mac / 无模拟器时，可用手机安装 **Expo Go**，扫描终端二维码直接预览。

### 构建 Android 测试 APK

无需发布到应用市场。首次构建需要 Expo 账号并将项目关联到 EAS；构建在 EAS 云端执行，不要求本机安装 Android Studio：

```bash
npx eas-cli@latest login
npx eas-cli@latest init
npm run build:android:preview
```

构建完成后，从终端输出或 Expo 构建页面下载 APK，在 Android 手机上打开安装；也可以连接已开启 USB 调试的手机，用 `adb install <APK路径>` 安装。首次安装时，Android 可能会要求允许该来源安装应用。

## 房贷计算器说明

**计算模型**：等额本息

```
月供 M = P × r × (1+r)^n / [(1+r)^n − 1]     r = 年利率/12，n = 期数
```

**提前还款两种模式**：

| 模式 | 规则 | 适用场景 |
| --- | --- | --- |
| 减少月供 | 期限不变，按剩余本金重算月供 | 降低每月压力 |
| 缩短期限 | 月供不变，反解新的期数 | 节省利息最大化 |

**边界处理**：全额还清（无后续月供，节省全部剩余利息）、零利率、输入校验（金额必须为正且提前还款额 < 剩余本金）、末期尾差自动吸收、金额展示四舍五入到元。

**导出**：还款计划支持导出 CSV（期数 / 月供总额 / 月供本金 / 月供利息 / 剩余总额），通过系统分享面板发送。

## 存款计算器说明

**计算模型**：定期存款（整存整取）单利

```
利息 = 本金 × 年利率 × 存款年数 + 本金 × 日利率 × 零头天数
日利率 = 年利率 ÷ 360        零头天数 = 月 × 30 + 天
```

**到期日**：按开户日「对年对月对日」推算，月末不足时取当月最后一天（如 1 月 31 日存 1 个月 → 2 月 28/29 日）。到期日与计息天数（实际日历天数）随结果一同展示。

**交互**：本金、期限（年 / 月 / 天）、存款日期、利率改动即时重算，无需点击；「常用利率」提供常见挂牌利率预设，也可手动输入实际执行利率。存期内遇利率调整，仍按开户日利率执行。

## 理财计算器说明

**计算模型**：活期理财，单利、按日计息，支持两种常用口径

```
七日年化：收益 = 本金 × 七日年化收益率 ÷ 365 × 持有天数
万份收益：收益 = 本金 ÷ 10000 × 每万份收益 × 持有天数
参考日收益 = 总测算收益 ÷ 持有天数
```

**交互**：「七日年化 / 万份收益」分段切换，聚焦另一行输入时自动切换口径，未参与计算的一行淡化显示；「常用收益率」「常用万份收益」提供参考值预设，持有天数可从 7 天到 730 天快速选择或自定义（上限 3650 天）。结果实时更新，展示总测算收益、本息合计与参考日收益。

**边界处理**：收益率上限 30%、万份收益上限 100 元；本金 / 天数缺失或天数非整数时给出提示；收益与日收益均保留两位小数，日收益由未取整的总收益折算，避免二次舍入。

## 个税计算器说明

**计算模型**：工资薪金所得预扣预缴，累计预扣法

```
累计应纳税所得额 = 累计收入 − 5,000 × 月份数 − 累计五险一金 − 累计专项附加扣除
本月应扣税 = 累计应纳税所得额 × 预扣率 − 速算扣除数 − 累计已扣税
到手工资 = 月薪 − 五险一金 − 本月应扣税
```

**预扣率表**（累计应纳税所得额）：3%（≤36,000）、10%（≤144,000，速算 2,520）、20%（≤300,000，16,920）、25%（≤420,000，31,920）、30%（≤660,000，52,920）、35%（≤960,000，85,920）、45%（>960,000，181,920）。

**页面流程**：输入页填写月薪、五险一金个人部分、专项附加扣除后点击「开始计算」，进入「年度扣税明细」页：累计收入 / 累计扣税总额 / 税后到手总额 / 月均扣税四张汇总卡，加实际税负、全年应纳税所得额，以及 12 个月逐月扣税与到手工资表（含合计行），支持 CSV 导出。

**边界处理**：累计应扣税额小于已扣税额时本期按 0 计（差额留待年度汇算清缴）；月薪为 0 或扣除项超过月薪时不产生负数税额；税额按月四舍五入到分，累计值由逐月税额累加，保证表格自洽。
